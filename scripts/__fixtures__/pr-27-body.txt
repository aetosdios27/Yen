## What and why

Integrates hardened Konto (`@konto-ledger/*@0.2.0`) behind a small Yen ledger interface in `packages/ledger`, tying double-entry money movements (`bank`, `donations`, `expenses`, `pending_spend`) to append-only hash-chained events in `@yen/eventlog` within the exact same database transaction.

Linear: YEN-24

## How to test

```bash
pnpm check
pnpm -r typecheck
pnpm build
pnpm --filter @yen/ledger test
```

## Risk

High (Financial logic & core transaction integrity):
- Money balance invariants: `bank - pending_spend = available`, and `bank + expenses = donations` across zero-sum entries.
- Dual-write transaction atomicity: failure between ledger write and event log write rolls back the entire transaction so neither persists.
- All 4 acceptance criteria covered with property-based and integration test suites.

<h3>Summary</h3>

Adds Konto-backed fund accounts and pairs money changes with hash-chained events in the caller's database transaction.
- Fund callers can track donations and expense spending in Konto.
- Fund event history can rebuild the ledger balances.
- Ledger tests use isolated databases and workspace-aware build settings.
